**游戏体验**
化身赛博佣兵，执行致命双重任务：潜入企业堡垒窃取尖端科技，终结目标CEO。然而你盗取的芯片中，竟蛰伏着复仇AI——它侵入你的神经，赋予骇客能力，缔结危险同盟。你能否突破企业天罗地网，查明与这电子魅影共猎同一目标的真相，最终揭开惊天阴谋？

**游戏按键操作**
- WASD 移动
- Shift 长按奔跑
- Ctrl 切换蹲伏
- Space 跳跃
- E 交互
- F 暗杀（只有在蹲伏状态能够触发）
- RMB 射击模式（只有有枪械才能触发）
- LMB 射击（只有有枪械并且进入射击模式才能使用）
- CAPSLOCK 切换越肩瞄准（只有有枪械并且进入射击模式才能使用）
- TAB/ESC 打开暂停菜单界面
- Q 进入骇客模式（只有有骇客芯片才能触发）
- 1 去物质化 （只有进入骇客模式才能使用）
- 2 读取内心 （只有进入骇客模式才能使用）
- 3 全息投影 （只有进入骇客模式才能使用）（单按3预览，再按左键放置）
- 4 重生信标 （只有进入骇客模式才能使用）（单按4预览，再按左键放置）

**Debug模式**
- Num1 显示所有Debug信息，角色无敌，获得钱、子弹、所有钥匙
- Num4 自杀

游玩实机视频中还藏着主策的小彩蛋
